# Methodology: what is computed vs. what is illustrative

NEXUS computes findings from uploaded data. Agents choose what to inspect and explain the results; deterministic tools compute the numbers.

## Current investigation engine (`/investigate`) — computed from uploaded data

Investigation statistics are recomputed from the uploaded dataset. Where a domain-specific tool pack is registered for a dataset's domain, its tools disclose their own deterministic formulas and assumptions the same way the generic tools do.

- **Anomaly / z-score** (`lib/nexus/adapters/generic/analyze.ts`): standard `(value - mean) / standardDeviation` on the column's own history.
- **Correlation** (`lib/engine/statistics.ts: pearsonCorrelation`): standard Pearson correlation coefficient between two numeric columns. Used both for the descriptive correlation list and for the precursor chain.
- **Precursor chain** (`lib/nexus/agentic/precursorChain.ts`): for each candidate signal, correlation against the mapped target (or the most anomalous signal, if no target is mapped) is scanned across lags 0–3 periods, pairing each row by its true index (`from[i]` with `to[i+lag]`) so a missing value mid-series only drops that one pair instead of silently misaligning everything after it. **Every tested lag is kept** (`allLags`), not just the winner — the lag that maximizes `|correlation|` is surfaced as the edge's headline value but is explicitly labeled an *exploratory pick from a multi-comparison search*, never asserted as the causal delay. The top signals by `|correlation|` become chain edges, ordered by lag (largest lag = earliest precursor).
- **Sample size, confidence interval, and significance** (`lib/engine/inferentialStats.ts`): each edge reports `n`, the exact count of row-index-aligned pairs where both columns were genuinely numeric (missing/null/empty cells are excluded, never coerced to 0 — see `lib/nexus/ingestion/numericSeries.ts`). Below `MIN_N_FOR_INFERENCE = 6` paired observations, no confidence interval or p-value is computed — the run reports an explicit insufficient-sample state (`ci95: null`, `pValue: null`) rather than a falsely precise number. Above that floor, the 95% CI for the correlation uses the Fisher z-transform, and the two-tailed p-value is exact (via the regularized incomplete beta function, computed from scratch — no ML/library black box). Because multiple lags are tested per edge, significance (`edge.significant`) is **Holm-corrected across that edge's lag scan**, not read off the single best lag in isolation.
- **Bootstrap stability** (`movingBlockBootstrap` in `lib/engine/inferentialStats.ts`): to check how sensitive the observed correlation is to resampling, NEXUS runs a **moving-block bootstrap** (400 iterations, deterministic via a seeded PRNG keyed to the edge and its winning lag) — never a naive row-resampling bootstrap, which would destroy the time-series/lag structure the analysis depends on. It reports the observed correlation, the bootstrap median, a 95% interval, the resample count, and a STABLE/MODERATE/UNSTABLE label from the sign-agreement share across resamples. **This measures sampling stability, not the probability of a future event** — it must never be phrased as a predictive probability.
- **Risk Indicator**: `mean(|correlation at best lag|) across the top edges × dataSufficiencyFactor`, where `dataSufficiencyFactor = clamp(observationCount / 30)` discounts short series. Thresholds: `<0.33` LOW, `<0.66` MEDIUM, else HIGH. This is a ranking heuristic over real computed correlations — it is **not** a fitted or calibrated probability of any real-world outcome, and the UI must never phrase it as one. `chain.causality` is always reported as `"NOT_ESTABLISHED"` — correlation, even lagged and statistically significant, does not establish causality. Every run exposes its own `methodologyNotes` describing exactly what was computed, visible under "Methodology" in the results screen.
- The live LLM Investigator/Skeptic agents choose *which* deterministic tool to run and *how to phrase* the hypothesis/challenge in natural language — they do not compute the numbers (enforced by the current `lib/nexus/agentic/` runtime).

## Statistical limitations (short version, for a judge/user question)

- **Risk Indicator ≠ a calibrated probability.** It is a descriptive ranking heuristic, not a fitted estimate of event likelihood.
- **Correlation ≠ causation.** Every precursor-chain edge, however strong or statistically significant, is reported with `causality: "NOT_ESTABLISHED"`. Lag correlation shows *co-movement with a lead time* in this dataset, not a verified causal delay.
- **The winning lag is an exploratory pick, not a pre-registered hypothesis.** It comes from scanning multiple lags per edge; significance is Holm-corrected across that scan specifically because testing several lags and reporting only the best one inflates the chance of a spurious "significant" result if left uncorrected.
- **Bootstrap stability is not event probability.** The moving-block bootstrap answers "how much would this correlation move if I resampled the series while preserving its time structure?" — it says nothing about the probability that a future event occurs.
- **True probability calibration is out of scope for this build.** It would require real labeled historical outcomes (did the predicted event actually happen, across many past cases) that NEXUS does not have access to. Until that data exists, NEXUS reports evidence, sample size, intervals, and robustness — and prefers the honest "evidence supports this hypothesis, but causality is not established" over a falsely precise "there is a 78% probability that X caused Y."

## Domain-specific tool packs

No domain currently has a prepared demo scenario or a registered deterministic tool pack — every investigation today runs on the generic six-tool pack described above. When a domain-specific tool pack is added (see `lib/nexus/templates/domainToolPack.template.ts` and [docs/task-adaptation-quickref.md](task-adaptation-quickref.md)), it is resolved the same way (via `resolveToolPack`), and the chain, the risk indicator, and every inferential-statistics field (`n`, CI, p-value, Holm correction, bootstrap) follow the current investigation engine regardless of which tool pack supplied the evidence.
